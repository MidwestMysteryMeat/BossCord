# Assets removed — licensing

The icon art that lived under this folder is from purchased packs licensed
to the project owner only, so it is **not in the repo**. The app references
these images at their original paths; fresh clones show broken/missing
icons until locally supplied. Originals live on the owner's dev machine
and the production server.

**For the full manifest — exact paths, formats, dimensions, per-folder file
counts, which sets are required vs optional, and the two one-line changes that
make the app look intentional with no art at all — see
[`ASSETS_NEEDED.md`](../../ASSETS_NEEDED.md) in the repo root.**

Nothing here is load-bearing: every missing image is a cosmetic 404, never a
crash.
